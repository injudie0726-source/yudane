# 引き継ぎメモ（クラウドセッション → PC上のローカルセッション）

作成：2026-09-28 / 前セッション：https://claude.ai/code/session_01WoyExBEhrzJ8QorYTVBXRV
ブランチ：`claude/uniqlo-tiktok-strategy-svlvg0`

## なぜ切り替えるか
前セッションはクラウド上のコンテナで動いていたため、(1) tiktok.com / youtube.com / uniqlo.com / torihada.co.jp / 日経 / WWD 等が遮断され原典が読めなかった、(2) 検索上限（200回/セッション）を使い切った、(3) ChatGPT・Gemini・Grok に接続する手段がなかった。PC上のローカルセッションなら、Chromeを直接操作してこれら全部ができる。

## 依頼者（俺ら）の要件
- 相手：TORIHADA（要確認：Driveに toridori.co.jp から共有フォルダあり。**トリハダ**か**トリドリ**か必ず確認）
- 仮説：突飛な企画より「膨大なバリエーションの微差を淡々と解消」「生活を作る提案」「選び方と使い方が簡単になる」に集中
- 資料は長文より **リファレンス動画 ＋ Vコン** が主役。数字の裏付けは付録でよい
- リファレンスは「こういうジャンルもある」ではなく、**実際に動画を見た上で**「この動画のこの部分をフックにしてユニクロに落とし込む」まで言える粒度
- 他のAIを使う：Gemini（動画理解）、ChatGPT（戦略の批判レビュー）、Grok（Xの生の声）
- 以前AIで作ったユニクロ動画（Codex or Claude製）がPC内にあるはず。トンマナの基準として探して参照する

## ローカルセッションでやること（優先順）
1. **相手の確認**：TORIHADA（トリハダ）かトリドリか。トリドリなら `research_notes/.../torihada_profile.md` を作り直す
2. **以前のユニクロ動画を探す**（PC内・Drive・チャット履歴）。トンマナの基準として `vcon/reference/` に置く
3. **リファレンス動画の収集と視聴分析（Gemini）**：`他AIへの質問文.md` の「3. Gemini向け」をベースに。対象：@uniqlo_jp 直近20本、GU／WEGO／ドンキ／M&S Romford／Gap Japan店員クリエイター、YouTubeの「極暖 超極暖 違い」「感動パンツ スマートアンクル 違い」上位。出力は「動画URL／何秒目のどの要素がフックか／ユニクロにどう落とすか」の表 → `リファレンス集_v1.md`
4. **Xの生の声（Grok）**：質問文の「2. Grok向け」→ `research_notes/.../x_voices.md`
5. **戦略の批判レビュー（ChatGPT）**：質問文の「1. ChatGPT向け」→ 反映点を `ユニクロTikTok戦略提案_v2.md` に
6. **一次確認**：提案書「付録C」の13項目を原典で確認し、数値を確定
7. **Vコン v0.2**：リファレンス分析を反映してカット割り・テロップを更新。可能なら実写素材やAI生成映像（Veo等）で撮影メモ部分を置き換え。感謝祭前の本命なので「極暖vs超極暖」を最優先
8. **資料の形**：プレゼン用に「仮説 → リファレンス → Vコン」の順で短くまとめ直す（長文の提案書は付録に）
