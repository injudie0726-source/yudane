# 構成案｜景瑚の実家の鉄筋屋で1日労働（先投げ用）

**目的**: この構成案を先にメンバー側へ投げておき、**景瑚＋相方の2人のスケジュールがドンピシャで空いた日**に取りに行く（恵む提案）。

| 項目 | 内容 |
|---|---|
| ランク | **A（構成先投げ・スケジュール待ち）** ★8/10収録で具体度最高 |
| 発端 | 「誰かの実家で1日労働させたい」→景瑚「俺の親父の仕事ガチでしんどい」（8/10収録 2本目 TC 7:55〜10:30） |
| ディテール（本人談） | ペール缶（鉄40kg）×50個をトラック積み／朝6時〜18時／日当1万円 |
| フォーマット | 横型 25〜30分（前後編も可）。縦型で「40kg×50個」の切り出し |
| 必須メンバー | **景瑚**（実家・案内役）＋ **相方1名**。本命は**蓮**（「蓮が行ったら効率の指摘しそう」と本人たちからキャスティング案あり） |
| フレックス枠 | 蓮NGの場合の相方: 拓実（「俺ずっと出れちゃう」体力枠）／純喜（バイト経験談と接続） |
| 人数 | 2名（3名まで可。増えると作業割り当てが薄まる） |
| 拘束時間 | **丸1日（朝6時〜18時）＋ 前後の移動**。前泊前提 |
| 場所 | 景瑚の実家の鉄筋屋（愛知想定） |
| 準備の重さ | 重。ご家族・会社の許諾、安全管理、作業着・安全靴・ヘルメット、保険 |

## 一言コンセプト
アイドルが親父の現場に入って、鉄40kgのペール缶を50個運ぶ。「家族の仕事を体で知る」ドキュメントと、蓮の効率指摘バラエティを同居させる。

## サムネ・タイトル案
- 「【日当1万円】景瑚の親父の現場で朝6時から働いたら地獄だった」
- 「JO1、鉄筋屋で1日労働」

## 事前に決めておくこと（先投げの目的）
1. ご家族・会社の出演可否と、どこまで映せるか（社名・現場・従業員）。
2. 作業内容の安全ライン（実際に40kgを持たせるか、回数上限、専門作業は見学のみ）。
3. 日当1万円のくだりをどう扱うか（本当に支払う画にするか、演出にとどめるか）。
4. 撮影日は「景瑚＋相方の2人が丸1日空く日」を先に押さえ、そこに合わせて現場調整。

## 進行（1日の流れ）
| 時刻 | 内容 | 見せ場 |
|---|---|---|
| 5:30 | 起床・実家出発。眠い2人 | 「日当1万円でこれ」の前振り |
| 6:00 | 現場入り。親父に挨拶、作業着着替え、安全説明 | 親父の一言で空気が決まる |
| 6:30〜9:00 | 午前の作業①: ペール缶（40kg）のトラック積み | 1個目で「無理」。個数カウンター表示 |
| 9:00 | 休憩。親父・従業員との会話 | 景瑚の子ども時代の話を引き出す |
| 9:30〜12:00 | 午前の作業②: 現場の段取り・運搬 | 蓮が効率を指摘し始める→親父の反応 |
| 12:00 | 昼飯。現場めし | 「これが毎日」の実感トーク |
| 13:00〜16:00 | 午後の作業: 残りのペール缶／後片付け | 体力の限界と、意外と慣れてくる画 |
| 16:00〜18:00 | 終業まで。掃除・戻し | 50個達成のカウント |
| 18:00 | 終業。日当（1万円）の受け渡し | 親父からの総評→締めの一言 |
| 夜（任意） | 実家で晩ごはん | 家族回としてのエモ着地 |

## 見せ場・仕込み（保険ネタ）
- **個数カウンター**（○/50）を常時テロップ表示。進捗が見える化されるだけで引きになる。
- 蓮の「効率の指摘」を親父に本気で返してもらう（現場のプロ vs 理論派）。
- 純喜が相方の場合は「壮絶バイト経験談」（⑨ゴミ屋敷の話）を昼休憩で回収。
- 景瑚の「親父の仕事ガチでしんどい」発言をオープニングで本人に再現させる。

## 撮影体制
- カメラ3台（作業寄り／全景／親父・従業員リアクション）＋ GoPro（ヘルメット装着で主観）。
- 音声はピンマイク2＋ガンマイク。現場ノイズが強いのでインタビューは休憩時に別撮り。
- 安全担当を1名専任（撮影と兼務しない）。

## 注意点
- 労働安全: 重量物は回数上限を決め、専門作業は見学。ケガ時の保険を確認。
- ご家族のプライバシー（住所・社名・顔出し）は事前合意の範囲だけ。
- 従業員の方の顔出し可否を個別確認。

## 派生
- 「誰かの実家で1日労働」シリーズ化（次は別メンバーの実家）。
- ⑧「1日バイト体験（接客）」と対にして、体力系／接客系の2軸で回す。
